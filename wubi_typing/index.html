五笔拆字规则

一书写顺序

按写字顺序拆：先左后右、先上后下、先外后内。

明 → 日 + 月

二取大优先

能凑成一个大的字根，就不要拆成几个小的。

克 → 十 + 兄　（不是 一 + 古 + 儿）

三兼顾直观

字根轮廓明显时，按看起来最自然的方式拆。

自 → 丿 + 目

四能连不交

能拆成「相连」的，就不拆成「交叉」的。

天 → 一 + 大　（不拆 二 + 人）

五能散不连

能拆成「散开」的，就不拆成「相连」的。

午 → 十 + 一　（不拆 丿 + 干）
